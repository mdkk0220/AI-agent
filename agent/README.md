# agent/ (5단계 예정)

4단계 분석으로 진로 후보가 정해진 뒤, LangGraph 취업 에이전트를 여기에 만듭니다. 샘플 공고 대신 `data/agent.db`의 실제 수집 데이터를 읽습니다.

계획

- 공고 조회 노드: 수집 DB의 `postings`와 분류 결과를 입력으로 사용
- 흐름: 공고 평가 → 점수 미달이면 종료 / 통과하면 자소서 초안 → 팩트체크(프로필에 없는 주장 검사, 최대 2회 재작성) → 사람 승인(interrupt) → 저장
- 회사 이름을 넣으면 그 회사에 맞는 자소서 형식을 추천하는 별도 그래프
- 지원 현황 트래커 (서류제출, 면접, 탈락)

규칙

- 자소서는 `profile.yaml`의 사실만 근거로 사용하고, 없는 내용은 `[TODO]`로 표시
- 사람이 승인하기 전에는 아무것도 저장하지 않음
- **자동 제출 금지**
