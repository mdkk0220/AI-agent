# 데이터 소스 조사

조사일: 2026-10-20. 출처는 사람인 Open API 사이트(`oapi.saramin.co.kr`)의 공개 안내 페이지입니다. 내용은 바뀔 수 있으니 수집 전에 다시 확인하세요.

## 사람인 채용정보 API

### 발급 절차 (공식 가이드 기준)

1. 이용신청
2. 승인 (승인 메일 수신). 소요 시간 안내는 사이트에서 찾지 못함
3. 로그인 후 `[Application] > [앱 등록]`으로 앱 생성
4. `[Application] > [내 앱리스트]`에서 앱 이름을 눌러 access-key 확인

### 호출

- `GET https://oapi.saramin.co.kr/job-search`
- 헤더: `Accept: application/json` (XML은 `application/xml`)
- 필수 변수: `access-key`

주요 요청 변수 (명세 기준)

| 변수 | 설명 |
|---|---|
| `keywords` | 기업명·공고명·업직종 키워드·직무내용 검색어. 공백/쉼표로 복수 지정(모두 포함) |
| `job_mid_cd`, `job_cd` | 직무 코드 (코드표 참고) |
| `ind_cd` | 산업/업종 코드 |
| `loc_cd` | 근무지 코드 |
| `published`, `published_min/max` | 등록일(시) 조건 → 증분 수집에 사용 |
| `updated`, `updated_min/max` | 수정일(시) 조건 |
| `deadline` | 마감일 (`today`, `tomorrow` 등) |
| `fields` | 선택 필드 (`posting-date`, `expiration-date`, `keyword-code`, `count`) |
| `start` | 페이지 번호 (0부터) |
| `count` | 1회 결과 수. **기본 10, 최대 110** |
| `sort` | 정렬 (`pd` 게시일 역순이 기본) |

주의: 와일드카드와 AND/OR는 지원하지 않고, **신입/경력 조건으로 서버에서 거르는 변수는 없음** (받은 뒤 `experience-level.code`로 직접 거름).

### 응답 필드 (명세 기준)

| 분류 | 필드 |
|---|---|
| 식별 | `id`(공고 번호), `url` |
| 상태 | `active`(1 진행/0 마감), `posting-timestamp`, `modification-timestamp`, `opening-timestamp`, `expiration-timestamp`, `close-type`(1 접수마감일/2 채용시/3 상시/4 수시) |
| 회사 | `company.detail.name`, `company.detail.href` |
| 직무·업종 | `position.title`, `position.industry`, `position.job-mid-code`, `position.job-code`, `keyword` |
| 조건 | `position.experience-level`(code 1 신입/2 경력/3 신입·경력/0 경력무관, min, max, name), `position.required-education-level`, `position.job-type`, `position.location`, `salary` |
| 선택 | `read-cnt`, `apply-cnt` (`fields=count`) |

**본문(상세 내용)은 제공되지 않음.** 공고 링크(`url`)만 옵니다.

에러 응답: 최상위에 `code`, `message`. `1` 키 미입력, `2` 유효하지 않은 키, `3` 유효하지 않은 요청 변수, `4` 일일 최대 요청 가능 횟수 초과, `99` 오류.

명세의 샘플 응답은 2019년 테스트 데이터라서, **실제 응답 구조는 키 발급 후 한 번 더 확인**해야 합니다.

### 한도와 범위 (FAQ·주의사항)

| 항목 | 내용 |
|---|---|
| 조회 가능 공고 | **현재 진행 중인 공고만.** 마감된 공고는 조회 불가 |
| 1회 호출 | 최대 110건 (`count`) |
| 하루 한도 | 주의사항에 "일 공고 호출 수 최대 500건"이라고 적혀 있음. 500건인지 500회인지 **불명확** → 보수적으로 500건 기준으로 설계 |

### 이용 조건 (서비스 이용자 주의사항 요약)

지켜야 할 것

- access-key를 타인에게 제공·공개·공유하지 않는다 (채팅·깃허브에 올리지 않는다)
- 이용신청·발급 과정에서 허위 정보나 타인 정보를 쓰지 않는다
- 본인 아이디가 도용되지 않게 관리한다

금지

- API를 사용한 서비스의 재판매, 이용요금 발생
- 서비스 이용자로부터 정보 제공 등 유·무형의 대가를 받는 행위
- 사람인의 제공 주체·제휴 관계를 오인하게 하는 행위(출처 사칭)
- 사람인 채용정보 API 서비스 소스 코드를 복제·수정해 파생 제품을 만드는 행위
- 위반 시 계정이 해지될 수 있음

이 프로젝트에 대한 적용

- 개인 학습·포트폴리오 용도이며 신청서의 이용목적과 일치
- 분석 결과를 공개할 때 "데이터 출처: 사람인 채용정보 API"를 밝히고, 사람인과 무관한 프로젝트임을 README에 적음
- 저장·공개 범위에 대한 명시 조항은 없음 → 수집한 공고 원본과 DB는 저장소에 올리지 않음

### 운영 방침

- 호출 사이 1초 이상 대기, 하루 호출은 한도 이내로 제한
- 첫 수집 이후에는 `published_min`/`updated_min`으로 새 공고만 증분 수집
- 어제 있었는데 오늘 조회되지 않는 공고는 마감 또는 삭제로 간주 (`last_seen` 추적)
- 마감일(`expiration-timestamp`)은 접수마감일형(`close-type` 1) 공고에서만 의미가 있음. 상시·수시·채용시 공고는 따로 구분
- 에러 코드 `4`가 오면 중단하고 실행 기록에 남김

## 대체·보조 소스 (미확정)

| 소스 | 확인된 것 | 확인 필요 |
|---|---|---|
| 공공데이터포털(data.go.kr) 채용 API | 중소벤처기업진흥공단 일자리매칭, 공공기관별 채용정보 API 등이 검색됨. 인증키 필요, 무료 | 데이터 범위(공공기관 중심), 호출 한도, 이용허락 범위 |
| 로켓펀치 Open API | 공식 문서에 가입 후 앱 등록 시 키가 즉시 발급되고 승인 절차가 없다고 적혀 있음. 채용공고 검색 예시 있음 | 이용 약관, 데이터 저장·공개 조건 |

사람인 한 곳만 쓰면 대기업 공채·스타트업 전용 플랫폼 공고가 과소 반영될 수 있습니다(소스 편향). 분석 결과에는 항상 "어느 소스 기준인지"를 적습니다.
